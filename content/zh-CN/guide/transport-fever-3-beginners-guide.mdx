## 入门指南：战役模式 vs. 自由模式

在直接投身于庞大的自定义沙盒之前，新手玩家应当先了解自己所能使用的工具。战役模式相当于一个注重叙事的互动式教程，在循序渐进的指引环境中向你介绍基础鼠标操作、路线规划以及货物需求。前期的战役任务包含各种幽默风趣的剧情——从清理施工地块上的野生动物，到为复古音乐节筹备物资供应——循序渐进地教会你物流线路之间是如何相互运作的。

在开启你的首张地图时，参考本《狂热运输3》新手指南可避免你在不必要的基础设施上挥霍启动资金。早期战役任务限制了可用的载具类型，让你可以毫无财务压力地掌握线路创建、车库管理和发车间隔等核心概念。

| 游戏模式 | 理想玩家体验 | 财务风险 | 解锁功能 | 推荐起始时代 |

| **剧情战役** | 学习界面与基础机制的新手玩家 | 极低（脚本保护缓冲） | 随任务逐步解锁 | 1900年（时代 1） |

## 掌控早期运输：1900时代

你的商业帝国始于1900年，这是一个由简易土路和马车主导的时代。在这个时代，私家车交通尚不存在，这意味着你的货运路线不会面临民用通勤车辆导致的交通拥堵。然而，载具速度缓慢且运载能力极为有限，意味着单次运输的利润空间非常微薄。

任何《狂热运输3》新手指南中都有一条基础建议：务必敬畏早期时代的运行机制——速度和路况决定生死。在早期的试玩评测中，例如 [CGMagazine 对《狂热运输3》的实际上手体验](https://www.cgmagonline.com/articles/previews/transport-fever-3/)，玩家指出未铺砌、维护不善的道路会导致严重的车辆磨损。如果你的马车或早期卡车在崎岖地形上行驶，维护成本将呈指数级上升，载具甚至可能在半途抛锚损坏。

| 早期基础设施类型 | 初始建造成本 | 维护费用 | 速度限制 | 车辆故障风险 |
| :--- | :--- | :--- | :--- | :--- |
| **土路 / 未铺砌道路** | 极低 | 低 | 15–20 mph | 高（频繁磨损） |
| **简易碎石路 / 碎石路面** | 中等 | 中等 | 25–35 mph | 中等 |
| **铺砌双车道公路** | 高 | 中到高 | 45–60 mph | 低 |
| **强化工业级通道** | 极高 | 高 | 60+ mph | 微乎其微 |

对生产中心与卸货站点之间的关键路线进行升级虽然需要前期资金投入，但它能预防高额的维修成本并缩短货物周转时间。铺设道路时，应尽量避免剧烈的地形坡度起伏。陡峭的斜坡会严重拖慢早期低马力载具的速度，让原本看似很短的路线变成缓慢且亏损的漫长旅途。

## 打造高利润的货物供应链

货运物流是你商业帝国的财务基石。原材料采集点（如伐木场、农场和油井）不会自动生产货物，除非有一条有效且处于激活状态的运输线将其连接到加工厂或有实际需求的消费市场。

正如本《狂热运输3》新手指南所强调的，货运运力不匹配会导致严重的现金流瓶颈。在为线路分配载具之前，务必仔细检查车辆支持的具体货物类型。一辆运载建筑木材的平板车绝不可能向发展中的城镇配送生鲜农产品或易腐食品。

```
[资源产地：农场 / 林场]
               │（原材料货运）
               ▼
[加工厂：磨坊 / 食品加工厂]
               │（加工成品货运）
               ▼
[城市商业区 / 工业区卸货点]
```

| 供应链环节 | 主要功能 | 理想载具配置 | 常见新手误区 |
| :--- | :--- | :--- | :--- |
| **开采节点** | 生产基础原材料（原木、谷物） | 大容量散货运输工具 | 远距离空车返程跑空趟 |
| **加工工厂** | 将原材料加工为成品 | 专用货运载具 | 原材料供应过量，超出工厂加工能力 |
| **城市集散中心** | 将最终产品分发至城市商业零售端 | 灵活敏捷的中速卡车 | 货运站设在商业辐射范围之外 |
| **多式联运枢纽** | 在公路、铁路和水运之间中转货物 | 调车机车与自动化货运终端 | 站台长度不足导致线路积压拥堵 |

为了最大化路线利润率，请尽可能实现双向满载运输。如果你的卡车将农作物运送至城镇附近的加工厂，检查该工厂是否会产出能运回起始枢纽的消费品。双向载货运输能有效将单程燃油与运营成本降低一半。

## 设计大运量客运网络

虽然货运能在初期提供稳定的原始资金积累，但随着城市中心的扩张，客运业务将带来指数级的规模增长。《狂热运输3》将城市区域划分为住宅区、商业区和工业区。市民居住在住宅区，前往工业区上班通勤，并前往商业区进行休闲和购物。

城市接驳整合是本《狂热运输3》新手指南探讨的另一个核心议题。将重型客运铁路总站直接建在市中心往往会产生高昂的拆迁费用，并导致当地噪声污染激增。更明智的做法是将大型客运火车站设在城镇外围，并通过本地的有轨电车和公交环线将通勤客流接驳输送至市中心。

与早期前作中地下或下沉式车站需要借助第三方 MOD 不同，《狂热运输3》内置了原生的地下有轨电车站。这让玩家可以在高密度的城市走廊中建造多层立体换乘枢纽，而无需大面积拆除现有摩天大楼。

| 客运层级 | 最佳运营角色 | 最佳站点间距 | 理想基础设施类型 |
| :--- | :--- | :--- | :--- |
| **本地接驳线** | 社区居民收集并输送至交通枢纽 | 200–400 米 | 地面有轨电车或市内公交 |
| **城市干线** | 高密度跨城区联络 | 500–800 米 | 地下有轨电车或专用快速公交道 |
| **区域通勤线** | 连接相邻城镇 | 1,500–3,000 米 | 复线内燃/电力客运列车 |
| **高速特快线** | 跨地图长途旅行 | 贯穿全图 | 专用高速铁路或区域客运客机 |

确保本地接驳线路保持高发车频率。《狂热运输3》中的乘客会综合评估出行耗时；如果等候电车的时间过长，旅客便会选择步行或自驾私家车出行，从而导致你的交通网络痛失票价收入。

## 财务管理与车队更新

流动资金耗尽是游戏走向失败最快的方式。车队中的每一辆载具都会持续产生成本，无论它是满载、半载，还是因为终点站堵塞而停滞不前。保持健康的财务纪律是本《狂热运输3》新手指南的核心支柱。

时刻留意载具的维护状况。随着车辆老化，其维护费用会逐渐攀升，直至运营成本甚至超过购置新车的费用。在车队管理器中设置自动换车阈值，一旦老化车厢和机车达到标准运营寿命，即可自动完成更换更新。

| 财务指标 | 理想目标基准 | 预警信号 | 纠偏措施 |
| :--- | :--- | :--- | :--- |
| **营业利润率** | 每条线路 > 35% 利润 | 降至 10% 以下 | 精简车队规模；调整等候间隔时间 |
| **载具状况** | “良好”至“极佳” | “较差”或“老化报废” | 在车队管理页面触发自动更新替换 |
| **车站利用率** | 70–85% 货物容量 | 货物积压溢出 / 货物开始损耗衰减 | 增加运力载具或延长货运站台 |
| **贷款利息** | < 月收入的 5% | 持续超过 15% | 在进行大规模扩张前优先偿还初期债务 |

在开局的前五年内，避免过度激进地偿还贷款。保留充足的流动现金，可以让你灵活地进行地形平整以铺设高效路基、升级拥堵严重的瓶颈路段，并在面临突发性的资源减产停工时平稳过渡，无需去申请利率极高的惩罚性紧急贷款。

## 常见问题解答

### 为什么我的货车在早期线路上频繁抛锚故障？
在《狂热运输3》中，路面状况直接决定了载具的磨损程度。让重载货车在未铺砌的泥泞土路上行驶会导致急速的机械损耗。将运输走廊升级为铺砌路面，并及时替换老化车龄的车辆，可以显著降低故障发生率并削减持续维护开销。

### 本篇《狂热运输3》新手指南如何帮助管理发车频率？
发车频率（Line Frequency）反映了指定车站两班载具到达之间的平均等待时长。通过在路线概览面板中监控发车频率，你可以灵活增加或减少载具，从而压低乘客等待时间，防止货物在车站堆积溢出，并保持旅客的高满意度。

### 我可以在沙盒模式中与其他玩家分享地图吗？
可以。《狂热运输3》在自由模式中提供了世界生成种子代码（Seed ID）。只要分享这串特定的字母数字组合种子，其他玩家就能生成一模一样的地图，包括相同的地形轮廓、城镇布局和工业资源点，以便共同交流探讨交通规划方案。

### 在开启自由模式前，是否有必要先完成战役模式？
虽然战役不是强制要求，但通关前期的战役任务相当于完成了极佳的实际上手教程。它会在财务风险极低且循序渐进的环境下，向你介绍购买载具、辐射覆盖区（Catchment Zones）、多站点路由以及地形改造等核心机制，让你在之后挑战大型自定义地图时更加得心应手。
