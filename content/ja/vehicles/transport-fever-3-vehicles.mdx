過去作と比較すると、これはスタジオ史上最大の初期ラインナップとなります。『Transport Fever 2』ではヨーロッパ、アメリカ、アジアの各地域を合わせて約200種類の乗り物でローンチされましたが、今作では世代ごとの階層をより深く設けることで、ゲーム序盤の単調さを解消することを目指しています。ゲーム内の20年間を単一の馬車や蒸気機関車だけに頼るのではなく、現実世界の段階的な技術の進歩を反映した過渡期のモデルも数多く登場する予定です。

また、コミュニティの報告によると、Urban Gamesは過去の名車モデルの引き継ぎ方法を再検討しているとのことです。『Transport Fever 2』の古い3D形状をそのまま移植するのではなく、主要アセットに対してビジュアルとサウンドの大幅な刷新が行われています。

## 主要な輸送カテゴリと予想される車両比率

広大なネットワークを構築するには、鉄道、道路、水運、航空の4つの輸送部門をバランスよく運用する必要があります。Transport Fever 3の車両規模を評価する際、各カテゴリにはそれぞれ異なる戦術的優位性、維持コスト、貨物積載能力が求められます。

```
       [Transport Fever 3 フリート (300+)]
                      │
       ┌──────────────┼──────────────┬──────────────┐
       ▼              ▼              ▼              ▼
      鉄道            道路            水運            航空
  (機関車/客貨車)  (トラック/バス)  (貨物船/旅客船) (旅客機/貨物機)
     ~45%           ~30%           ~15%           ~10%
```

### 1. 鉄道：機関車、動力分散方式車両（電車・気動車）、客車・貨車
鉄道は依然として本シリーズの絶対的な主役です。機関車は、開拓期初期のアメリカの4-4-0蒸気機関車やイギリスのタンク機関車から、超高速列車セット（最新のTGV、ICE、新幹線の後継機など）に至るまで多岐にわたります。重量貨物輸送には専用の重連ディーゼル機能が強化され、急勾配における単機牽引力の不足というプレイヤーの不満に対処しています。

### 2. 道路物流：配送バン、大型トラック、路線バス
道路輸送は、不可欠なファーストマイルおよびラストマイルの接続手段です。道路車両の種類は、都市専用の特殊作業車両、都市間高速バス、各世代の大型輸送車へと大幅に拡張される見込みです。初期の蒸気トラックから、20世紀半ばの象徴的なキャブオーバー型、そしてゲーム終盤の水素燃料やバッテリー駆動の電動貨物コンボイまで期待されます。

### 3. 水運：ハシケ、フェリー、近代貨物船
過去作では水運物流が副次的なものになりがちでしたが、海洋マップの拡大と航行可能な河川網の導入により、その重要性が高まっています。船舶リストには、喫水の浅い河川用ハシケ、沿岸旅客フェリー、ばら積み鉱石運搬船、メガコンテナ船などが登場する予定です。

### 4. 航空：地方コミューター機から大陸間貨物輸送機まで
航空輸送は、列島マップや大陸横断マップでの長距離移動の架け橋となります。収録予想としては、1920年代の小型複葉郵便機から、ターボプロップの地方シャトル機、ワイドボディの国際旅客ジェット機、さらにはノーズローディング式の専用貨物輸送機までが想定されています。

| カテゴリ | 予想される構成比 | 主な強み | 戦略的役割 |
| :--- | :--- | :--- | :--- |
| **鉄道（列車・貨車）** | 約45% | 圧倒的な輸送量、長距離高速走行 | 都市間幹線および大量の産業物資輸送 |
| **道路（トラック・バス）** | 約30% | 抜群のルート柔軟性、低い初期投資 | フィーダー路線、都市内公共交通、ラストマイル配送 |
| **水運（船舶・ボート）** | 約15% | トンあたりの燃料費が最安、巨大な積載量 | 島嶼部から本土への輸送、河川流域のサプライチェーン |
| **航空（旅客機・貨物機）** | 約10% | 最速の移動速度、地形の影響を受けない | 速達貨物、高付加価値旅客輸送、山岳越え |

## 技術的進化：オーディオ、物理演算、ビジュアルのディテール

Transport Fever 3の車両の視覚的リアリティはシリーズの新たな基準を打ち立てることになりますが、コミュニティはそれと同じくらいシミュレーションの奥深さに期待を寄せています。以前の作品では、ディーゼル機関車や電気機関車に比較的固定的なオーディオループが使われており、2.5%の山岳勾配で重量貨物を牽引する際の強烈な機械的負荷を十分に表現できていませんでした。

プレイヤーからのフィードバックを受け、新しいサウンドシステムはスロットルノッチを基準に再設計されています。ディーゼル電気機関車はアイドリング、ノッチ1、ノッチ8の間を動的に遷移し、牽引する列車の総重量や現在の勾配に応じて、ターボチャージャーの過給音や排気量をリアルタイムに変化させます。

```
車両物理演算の計算式：
加速度 = (牽引力 - 列車抵抗) / 総質量
※列車抵抗の内訳：
- 転がり摩擦抵抗
- 空気抵抗（速度の2乗に比例）
- 勾配抵抗（質量 × 重力加速度 × 勾配角度）
```

さらに、パーティクルシミュレーションも目覚ましい進化を遂げています。単調な暗いスプライト煙が繰り返されるのではなく、蒸気や初期ディーゼルの排気煙はボリュメトリック（立体的）に立ち上り、周囲の風、トンネルの入口、走行速度などに自然に反応します。

| 機能分野 | Transport Fever 2の基準 | Transport Fever 3での進化 |
| :--- | :--- | :--- |
| **エンジン音響** | 一定回転数のループ音、単純なドップラー効果 | マルチノッチのスロットル音響、ターボ回転音、レール摩擦鳴き音 |
| **排気・パーティクル** | 平面的な2Dビルボードスプライト | ボリュメトリック煙、陽炎（熱歪み）、天候による拡散 |
| **経年劣化と摩耗** | テクスチャ全体の一様なサビ度スライダー | プロシージャルなウェザリング、台車・車輪への泥汚れ蓄積 |
| **貨物の積み下ろしアニメーション** | 貨物の瞬間的なスナップイン表示 | クレーンによるコンテナ荷役、ホッパ車への鉱石投入動作 |
| **運転席・乗務員室** | ローポリゴンの簡易的な内部空間 | 精細な3D内装、動的なメーター類、運行テレメトリ表示 |

## コミュニティのウィッシュリストと地域の独自車両

Steamフォーラムでのプレイヤーの議論では、これまであまり収録されてこなかった地域の車両に常にスポットが当てられています。西ヨーロッパと北米はバニラ（標準状態）でも充実したラインナップを誇ってきましたが、交通ファンからは東欧、中南米、アジアの独自車両を求める声が強く上がっています。

特に、Transport Fever 3の車両カスタマイズに期待を寄せるプレイヤーたちは、ソ連時代のカマズ（KamAZ）やウラル（Ural）の大型トラック、PAZ旅客バス、チェコ製のタトラ（Tatra）路面電車などの名車を挙げています。これらの頑丈な車両は厳しい気候や未整備のインフラに最適であり、20世紀半ばの東欧圏をテーマにした工業シナリオにふさわしい、無骨で味わい深い雰囲気を醸し出します。

また、都市の公共事業・ユーティリティ車両に対する需要も非常に高いです。道路を単に配送トラックや標準的な路線バスだけに限定するのではなく、スクールバスや清掃車両、さらには巨大過密都市を機能させる専用の地下鉄車両を望むプレイヤーの声が多数寄せられています。

| 車両タイプ／ブランド | 発祥地域 | ゲームプレイで期待される役割 | コミュニティ需要度 |
| :--- | :--- | :--- | :--- |
| **KamAZ / Ural 重トラック** | 東欧 | 悪路や山岳地帯での高トルク重量貨物輸送 | 極めて高い |
| **地下鉄車両セット** | 全世界（都市部） | 立体交差による高密度の都市内旅客路線 | 必須レベル |
| **Tatra 近代型トラム** | 中欧 | 中規模輸送能力を持つ都市型旅客コリドー | 高い |
| **特殊タンクローリー車列** | 北米 | 危険物輸送（化学薬品、原油、精製燃料） | 中程度 |
| **新幹線／リニア路線** | 東アジア | 超高速の拠点間旅客幹線 | 高い |

## 車両管理とデポ（車庫）の運用

複数の時代にわたって運行フリートを維持するには、賢明な財務計画が欠かせません。『Transport Fever 3』では、車両維持費の経済的負担が、車齢、運行頻度、路線の過酷さに応じてダイナミックに変動するように設計されています。

保有車両の収益性を最大化するために、運行管理者は以下の3つの重要な運用フェーズを注視する必要があります。

1. **導入フェーズ**：路線の地形に合わせて牽引力を選定する。平坦な穀物ルートに高出力の機関車を導入するのは、資金と燃料の無駄遣いになります。
2. **運用調整**：発車間隔と貨物の積載待ち制限を調整する。乗車率や積載率が半分のTransport Fever 3車両は、運行を続ける毎月ごとに営業利益を圧迫します。
3. **更新と改修**：維持費の推移に常に目を配る。車両が設計寿命を超えると、メンテナンスコストは急激に跳ね上がります。古い車両をよりクリーンで大容量の新型車両に置き換えることで、突発的な赤字転落を防ぐことができます。

```
車両ライフサイクル管理戦略：
[新車導入] ──► [中間大規模改修：状態100%を維持]
                                │
                                ▼
[売却/廃車] ◄── [高額維持費アラート：次世代機へ更新]
```

## MOD機能と後方互換性

MOD（改造データ）の存在に触れずにこのシリーズを語ることはできません。Steamワークショップは何年にもわたり『Transport Fever 2』を支え続け、何万種類ものカスタム機関車、クラシックカー、飛行機、リペイントなどを提供してきました。

続編に向けて、プレイヤーは既存のワークショップモデルがTransport Fever 3の車両へシームレスに変換できるかどうかを熱心に見守っています。基本的なファイル構造（`.mdl` メッシュ定義やマテリアルスクリプトなど）はUrban Gamesのエンジン間で類似した設計が保たれることが多いものの、強化された車内照明、カスタムノッチ音、ダイナミックパーティクルエミッターなどの高度な機能に対応するには、MOD制作者による旧アセットの更新作業が必要になります。

これまでの傾向から見ても、発売後数週間以内にMOD変換スクリプトが登場し、コミュニティのクリエイターがアップグレードされたシェーダーを用いて過去の車両群を新エンジンにインポートできるようになる見込みです。これにより、たとえ初期の300種以上の基本ラインナップにお気に入りのマニアックな地域列車が含まれていなくても、コミュニティのMOD職人たちがすぐにその溝を埋めてくれるはずです。

## よくある質問（FAQ）

### 『Transport Fever 3』の基本ゲームには何種類の車両の収録が確定していますか？
開発元の初期プレビューによると、発売時点で複数の歴史的時代にまたがる鉄道、道路、水運、航空の各分野から300種類以上の車両が登場することが公式に発表されており、開発の進行に伴いその数はさらに増えています。

### 『Transport Fever 2』の車両MODは『Transport Fever 3』でも使えますか？
新しいグラフィックエンジンでのライティング、物理演算、動的サウンドシステムの刷新により、そのまま導入して動作させる直接的な互換性は限定される可能性があります。しかし、MOD変換ツールやコミュニティ製のコンバーターによって、クリエイターが従来の車両デザインを新仕様に更新して移植できるようになると強く期待されています。

### 『Transport Fever 3』には専用の地下鉄やメトロ車両が登場しますか？
立体交差化された都市交通や地下鉄システムは、コミュニティフォーラムで最も要望の多い機能の一つです。路面電車（トラム）の搭載は確実視されていますが、ファンはネイティブな地下旅客鉄道システムの導入について、開発者のロードマップ発表を心待ちにしています。

### 車両の摩耗やメンテナンスは運行にどのような影響を与えますか？
Transport Fever 3の車両は、稼働時間が蓄積するにつれて維持費用が増加します。車両にはプロシージャルなウェザリング（経年劣化・汚れ）効果が適用され、管理者は車両の買い替えコストと月々の維持費の高騰とのバランスを常に考慮しながら運行する必要があります。
