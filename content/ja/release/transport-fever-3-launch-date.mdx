## 刷新された物流：海洋産業、貨物トラム、そして倉庫機能

『Transport Fever 3』における物流は、前作から劇的な進化を遂げています。これまでの作品における貨物ネットワークは、単純な2点間接続と基本的な道端のトラック停留所、または専用貨物ターミナルに頼ることが大半でした。しかし本作ではその固定概念を打ち破り、海洋石油プラットフォームや商業漁場といった沖合（オフショア）開発を含む、35種類以上の多彩な産業セクターが導入されます。

さらに、熟練の物流設計者（プレイヤー）の経験から、以前より中間配送の必要性が強く叫ばれていました。『Transport Fever 3』は、最終配送の前に物資を集約するために設計された専用の物流倉庫と貨物ハブを実装することで、この課題を解決しています。

| 物流機能 | Transport Fever 2 | Transport Fever 3 | 実際のゲームプレイへの影響 |
| :--- | :--- | :--- | :--- |
| **産業セクター** | 約15種（内陸のみ） | 35種以上（内陸および海洋） | 海洋資源の採取や外洋航路の計画要素を追加 |
| **都市型貨物トラム** | MODのみ／限定的な回避策 | ネイティブで完全対応 | 線路上で物資を配送することで都心の渋滞を緩和 |
| **貨物のバッファ保管** | 駅の保管許容量のみ | 専用の流通・配送倉庫 | 輸送プラットフォームを逼迫させることなく貨物を一時保管可能 |
| **工場の拡張** | 硬直的な供給レベル | 動的な需要と労働者の通勤 | 通勤労働者の到着により工場の生産スピードが向上 |

これらの物流システムの変更は、都市内部の貨物輸送を根底から変革します。専用の貨物トラムを活用することで、事業者は混雑した街の広場に大型セミトレーラーを進入させることなく、精製された完成品を商業エリアへ直接届けることができます。『Transport Fever 3』の発売日に向けて輸送ルートを計画するなら、鉄道、水運、ライトレール（路面電車）の流通をシームレスに融合する複合ハブ（インターモーダルハブ）の扱いに慣れておくことが重要です。

## 現代的なインフラ、柔軟な道路網、高度な交通シミュレーション

従来の作品では都市部の渋滞が常に大きな課題であり、車両の経路探索（パスファインディング）によって交通が1車線に固定されてしまうことも珍しくありませんでした。『Transport Fever 3』は、道路設計ツールとドライバーの挙動を根本からオーバーホールすることで、このフラストレーションを解消しています。刷新された道路建設スイートでは、自由な車線構成、トラム専用軌道、高速道路専用のインターチェンジランプ、そして機能的な追い越しメカニクスが提供されます。

また、インフラツールキットも再構築され、125年以上にわたる技術進化を網羅するモジュール式コンポーネントが用意されています。

| インフラ構成要素 | 主な機能 | タイクーン視点のメリット |
| :--- | :--- | :--- |
| **設定可能な車線分岐** | 右左折レーンの方向指定やバス／トラム専用レーンの設定 | 配送トラックの後ろに旅客交通が巻き込まれて立ち往生するのを防止 |
| **郊外型トラム路線** | 地方の幹線道路沿いに都市間ライトレール軌道を敷設 | 近隣の通勤ベッドタウンを接続する際の建設コストを削減 |
| **モジュール式飛行場・ターミナル** | 滑走路、格納庫、誘導路を各時代に合わせてアップグレード | 初期の複葉機から巨大な国際線ジェット旅客機まで幅広く対応 |
| **沖合港湾＆係留施設** | 深水バース（深水岸壁）や専用フェリー乗り場の建設 | 海洋リグからの液体バルク貨物や一般貨物の効率的な積み替えを実現 |
| **高速道路ランプの統合** | 滑らかな高低差を持つ独自のオンランプ・オフランプをスナップ配置 | 主要な高速環状・連絡道路での急激な速度低下を解消 |

これらの建設コントロール機能により、プレイヤーは交通渋滞が配送の信頼性や市民の満足度を損なう前に、ボトルネックを未然に解消することができます。

## 生き生きとしたバイオーム、ダイナミックな天候、そして昼夜サイクル

『Transport Fever 3』では、視覚的な没入感と環境メカニクスがエンジンレベルで刷新されています。静的な真昼のライティングの下で運行するのではなく、物理ベースの大気照明、リアルタイムの雲シミュレーション、動的な天候変化を伴う完全な24時間昼夜サイクルの中で輸送網を運営することになります。

本作は従来の温帯や乾燥帯の地形にとどまらず、過酷で美しい新たな「亜寒帯バイオーム」をはじめとする4つの多彩な気候帯を収録しています。

| 気候帯 | 主要な地形と特徴 | 固有の運営上の課題 |
| :--- | :--- | :--- |
| **温帯** | なだらかな緑の渓谷、密密な河川水系 | バランスの取れた降水量、標準的な維持費、拡大する人口 |
| **亜寒帯（新登場）** | 凍結したツンドラ、湿地帯、永久凍土 | 困難な地形造成、天候による劣化、高額な軌道敷設コスト |
| **砂漠** | 乾燥した広大な大地、点在するオアシス集落 | 水資源と産業資源の間の長距離輸送、乏しい森林被覆 |
| **熱帯** | 密集した諸島、急峻な島の尾根 | 旅客フェリー、沿岸海運、航空便への高い依存度 |

それぞれの気候は、鉄道の勾配設計や航路の設定方法に直接影響を与えます。例えば亜寒帯の地形では、ぬかるんだ湿地帯を通過する際に慎重な線形改良が求められ、橋梁の建設費用とコストのかかる迂回ルートの選択を天秤にかける必要があります。『Transport Fever 3』の発売日が訪れた際、維持管理コストを予算内に抑えるためには、環境特性を把握することが成功の鍵となります。

## 奥深い経営シミュレーション、歴史的時代区分、そしてModツール

『Transport Fever 3』の根幹にあるのは、緻密で戦略的な財務マネジメントです。マネージャー向けに動的な融資契約、専門的な業績インセンティブ、そして都市の成長を左右する包括的な公害指標が用意されています。賑やかな繁華街に時代遅れの黒煙を吐く蒸気機関車を走らせれば住民の怒りを買い、地域評価スコアの低下や都市成長の停滞を招くことになります。

プレイヤーを長きにわたって惹きつけるため、本作には125年以上にわたる輸送の進化の中で、歴史に着想を得た物流危機に立ち向かう充実したストーリーキャンペーンが収録されています。

### 車両ラインナップと歴史の進化

*   **275種類以上の本格的な車両：** 歴史に忠実な蒸気機関車、最新鋭の電車（EMU）、長距離大型貨物機、ヘリコプター、外洋航行タンカーなどを自在に指揮できます。
*   **時代の変遷：** 19世紀後半から現代に至るまで、街並みの建築様式、市民の服装、自家用車などがシームレスに変化していく様子を体感できます。
*   **カスタムタイクーン難易度：** 経済ペナルティ、融資利率の変動性、車両故障率などを設定し、自分好みの挑戦レベルに調整可能です。
*   **サンドボックス＆ジオラマモード：** 資金制限を完全に解除し、広大で精緻極まるジオラマ展示レイアウトや車両基地を自由に建設できます。

コミュニティによる創作活動は、本シリーズのアイデンティティの中心であり続けています。『Transport Fever 3』は、強化されたゲーム内マップエディターと統合Modブラウザを搭載してリリースされます。Mod制作者はオリジナルの車両スキン、時代考証に基づいたアセット、カスタムスクリプトを簡単に公開でき、『Transport Fever 3』の正式発売後も末永く無限のリプレイ性を楽しむことができます。

## よくある質問（FAQ）

### 『Transport Fever 3』の確定した発売日はいつですか？
Urban GamesおよびGood Shepherd EntertainmentはPCデジタルプラットフォームでの予約購入を開始していますが、現時点で『Transport Fever 3』の具体的なカレンダー上の発売日は確定していません。パブリッシャーの公式発表によると、通例のベータテストサイクルを経て、2026年後半または2027年初頭のリリースを予定しています。

### 『Transport Fever 3』には現代の航空機やヘリコプターも登場しますか？
はい。収録が確定している車両ラインナップは、輸送の歴史125年以上にわたる275種類以上の乗り物で構成されています。これには現代の民間ジェット旅客機、特殊貨物輸送機、コミューター機、そして海洋リグや手狭な都市部のヘリポートに対応するヘリコプターが含まれます。

### 資金や経営のプレッシャーを受けずに、純粋な景観・装飾用ネットワークを建設できますか？
はい。『Transport Fever 3』には完全なサンドボックスモードを含む、柔軟にカスタマイズ可能な難易度設定が備わっています。資金コスト、車両維持費、契約の納期制限などを無効化し、自分のペースでジオラマ、理想の都市、風光明媚な鉄道網を建設することができます。

### 『Transport Fever 2』の既存Modは新作でも使えますか？
『Transport Fever 3』はライティングと経路探索システムが向上した改良型ゲームエンジン上で動作しますが、開発元は拡張されたゲーム内Modエディターおよびブラウザを提供します。コミュニティのMod制作者には、人気のある車両アセットやマップを変換し、新しい物理演算や大気レンダリングシステムを最大限に活用できるようにするための改良されたツールが提供されます。
