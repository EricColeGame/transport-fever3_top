キャンペーン内の各ステージには、当時の技術水準を忠実に再現した制約が課されます。初期のシナリオでは、速度が遅く積載量も限られ、急勾配で大きな運行ペナルティが発生する車両しか使用できません。時代の針が進むにつれて、**Transport Fever 3のキャンペーン**では、旧式の蒸気機関車や外輪船を順次退役させ、重ディーゼル機関車、電気高速鉄道、大型タンカー、長距離航空機へと置き換えていくことが求められます。

高コストな輸送ネットワークの陳腐化を防ぐためには、歴史的な技術革新とミッション目標がどのように連動しているかを正確に把握することが不可欠です。

## コアメカニクス：ボトルネック、運行スケジュール、維持費の管理

標準的なフリープレイとは異なり、**Transport Fever 3のキャンペーン**におけるミッションでは、根本的な設計ミスを修正するための無尽蔵の猶予はほとんど与えられません。収益は期限内に配達を完了して初めて発生する一方、ネットワーク上に配置されたすべての車両に対して維持費が常に発生し続けます。

キャンペーンシナリオでよくある落とし穴は、下流の需要を確認する前に輸送回廊へ車両を過剰投入してしまうことです。最適化されていない交差点で都市内配送トラックが立ち往生し、貨物デポから搬出在庫を掃き出せなくなれば、高額な貨物列車は空荷同然で走行することになり、会社の資金を急速に食いつぶしてしまいます。

綿密なルート設計を行うには、利用可能なすべての輸送モードにおいて、車両速度、積載時間、ターミナル容量を慎重に評価する必要があります。

| 輸送モード | 初期導入コスト | 運行維持費 | 最適なミッション用途 | 主な戦略的欠点 |
| :--- | :--- | :--- | :--- | :--- |
| **道路車両** | 非常に低い | 低い（車両数に比例） | 都市内の短距離配送、貨物ターミナルへの接続路線 | 市街地の渋滞や信号機の影響を受けやすい |
| **鉄道** | 高～非常に高 | 中～高 | 大量のばら積み貨物、都市間の長距離旅客 | 整地、ポイント切り替え、信号システムの導入が高額 |
| **海上輸送**| 中程度 | 容量比で低い | 島嶼間の大量輸送、沿岸部のサプライチェーン | 最高速度が遅く、喫水の深い進入水路が必要 |
| **航空輸送** | 極めて高い | 非常に高い | マップ端間のプレミアム旅客路線、緊急の軽量貨物 | 広大なターミナル用地が必要で、騒音公害が大きい |

コミュニティからの報告によると、本作で導入された昼夜の交通量変動システムによって、交通密度が大きく変化することが判明しています。オフピークの時間帯に貨物輸送を集中させ、日中の鉄道ダイヤを旅客サービスに割り当てることで、共用軌道における壊滅的な鉄道渋滞を防ぐことができます。

## ミッション攻略手順：初期の蒸気機関から高速回廊まで

**Transport Fever 3のキャンペーン**でミッションをクリアするには、ブリーフィングで提示される時代や地形に応じて、明確な優先順位を設定して挑む必要があります。最初から壮大な大陸横断路線を敷設しようとするのではなく、まずはコンパクトで自活可能な収益ループを確立することが鉄則です。

### ステップ1：利益率の高い産業基盤を確立する
すべてのシナリオの開始時に、物理的な距離が近い原材料の循環ループを特定しましょう。鉄鉱石鉱山と石炭鉱床を単一の複線鉄道トランクラインで製鉄所に結ぶことで、最小限の軌道投資で即座に資本を生み出すことができます。このメイン路線が安定した余剰利益を生み出すようになるまでは、支線の建設は控えましょう。

### ステップ2：都市内配送フィーダー網を構築する
貨物列車は、市街地のすぐ外側に配置された地域ステーションに貨物を荷下ろしすべきです。そこから専用のトラック路線を配備し、加工製品を商業地区や工業地区へ直接輸送します。重い貨物列車を混雑する市街地に乗り入れさせないことで、将来の通勤ターミナル用の貴重な都市用地を確保できます。

### ステップ3：平面交差を立体交差化する
ミッションタイマーが進み生産ノルマが増加するにつれて、鉄道の平面交差は致命的なチョークポイントになります。分岐器や交差部を高架橋、トンネル、立体交差にアップグレードし、信号待ちによる停止を起こさずに複数編成の列車を円滑に走らせ続けましょう。

| ミッションのマイルストーン | 主な目標 | よくある障害 | 推奨される戦術的解決策 |
| :--- | :--- | :--- | :--- |
| **フェーズ1：スタートアップ** | 年間キャッシュフローの黒字化 | 借入金の利息が路線の収益を上回る | 車両数を制限し、満載になるまで発車を待機させる |
| **フェーズ2：拡大** | 成長する2〜3の集落へ物資供給 | 都市渋滞による貨物トラックの遅延 | 環状道路を整備し、旅客用と貨物用のデポ出入口を分離する |
| **フェーズ3：統合** | 複合交通結節点（ハブ）の建設 | プラットホームの混雑と貨物の消失 | ターミナルの有効長をモジュール単位で拡張し、バイパス線を増設する |
| **フェーズ4：総仕上げ** | 高級品の輸送または高速接続 | 旧式車両群の更新コストが高騰 | 車両形式を標準化し、段階的な車両更新を実施する |

プレイヤーの経験則として、運行頻度（フリークエンシー）を軽視することが、制限時間付きのボーナスタスクに失敗する最大の原因です。巨大で鈍重な列車を走らせて工場の搬出口を何ヶ月も放置するよりも、中規模編成の列車を高頻度で運行する方が、供給の信頼性評価を高く維持しやすくなります。

## 5つ星メダルを獲得するための複合輸送サプライチェーンの最適化

キャンペーンシナリオには、主要な運用目標に加えて、ボーナスメダルが手に入る任意のサブ目標が用意されています。**Transport Fever 3のキャンペーン**を通じて最高評価を獲得するには、複数の輸送レイヤーを調和させ、隙のない物流ネットワークへと統合しなければなりません。

サブ目標では多くの場合、厳格な納品ノルマの維持、環境負荷の低減、あるいは厳しい期日内での乗客満足度基準の達成などが求められます。

```
[原材料の採掘・採取：鉱山／森林／油井]
                     │
                     ▼（ばら積み貨物：鉄道／大型輸送船）
[加工・精製施設：製油所／製鉄所／工場]
                     │
                     ▼（製品貨物：複合貨物列車／航空貨物）
[地域配送ターミナル（都市郊外）]
                     │
                     ▼（ラストワンマイル配送：電気トラック／配送バン）
[都市の商業・工業地区]
```

深刻な財政赤字を招くことなくこれらの入り組んだサプライチェーンを調整するには、インフラのアップグレードを明確なシナリオのマイルストーンに合わせて実施しましょう。

| ミッション目標カテゴリー | 一般的なボーナス要件 | 最適な戦略的アプローチ |
| :--- | :--- | :--- |
| **輸送量** | Yヶ月以内にXユニットの貨物を輸送 | 待避線を同期させた専用の複線貨物ラインを運行する |
| **都市間接続** | 複数の町を旅客回廊で接続 | 停車時間を最小限に抑えた中容量のディーゼルまたは電気気動車を高頻度で投入する |
| **財務健全性** | 銀行ローンを利用せずに目標純資産を達成 | インフラの規模をコンパクトに抑え、余剰営業利益を段階的に再投資する |
| **市民満足度** | 住宅地付近の排出ガスと騒音を抑制 | 重貨物鉄道を都市郊外へ迂回させ、都市内では電気配送バンを使用する |

主要な資源採掘拠点における生産レートは常に監視してください。森林や採石場の産出ティアが上がらない場合、下流の加工施設が原料不足に陥り、高価な輸送リソースが遊休化してしまいます。

## 予算管理と借金スパイラルの防止

健全な財務規律こそが、苦戦する経営者と成功を収めるタイクーンを分ける決定的な要素です。**Transport Fever 3のキャンペーン**では、ミッションの序盤に過剰な銀行融資を受けると、複利の利息支払いが薄い営業利益を食いつぶし、抜け出せない借金スパイラルに陥る危険があります。

高額な橋梁を架けたり山脈をトンネルで貫通させたりする前に、その設備投資を正当化できる損益分岐点の輸送量を計算してください。土木工事や急勾配の整地調整には莫大な費用がかかり、初期の開業資金など瞬く間に消し飛んでしまいます。

| キャンペーンフェーズ | 目標インフラ予算 | 目標フリート配分 | 最大推奨負債比率 |
| :--- | :--- | :--- | :--- |
| **ミッション初期（0〜5年目）** | 流動資本の60% | 流動資本の30% | 借入可能限度額の50%未満 |
| **ミッション中期（5〜15年目）** | 収益の35% | 収益の45% | 借入可能限度額の25%未満 |
| **ミッション後期（15年目以降）** | 収益の20% | 収益の60%（車両更新） | 0%（未払いの融資を完済） |

バランスシートを守るために、以下の鉄則を守りましょう：

*   **復路の空荷走行を避ける：** 可能な限り、往路で原材料を運び、復路で消費財や中間素材を運べるような三角輸送ルートを設計しましょう。
*   **車両の更新時期を分散させる：** 40両の旧型蒸気機関車を単一の年度に一括更新すると、手元の流動資金が瞬時に枯渇します。保有車両のメンテナンス設定を利用し、グループごとに段階的かつ自動で車両更新が行われるようにしてください。
*   **低収益路線を毎年監査する：** 毎会計年度の終わりに、路線リストを収益性順に並べ替えましょう。航空貨物や鉄道回廊が2年連続で赤字を出している場合は、ルートを短縮するか、車両数を削減するか、発車頻度を見直してください。

規律ある予算編成を守り、交通のボトルネックを体系的に解消していくことで、あらゆるチャプターを通じて、立ち上げたばかりの輸送会社を世界トップクラスの物流大企業へと育て上げることができます。

## よくある質問（FAQ）

### Transport Fever 3のキャンペーンでボーナス目標を達成する最も効率的な方法は何ですか？
任意のサブ目標に手を出す前に、まずは盤石で収益性の高いメインの貨物路線を確立することに集中してください。ボーナス目標では多くの場合、初期段階では赤字になるような迅速な出荷や特殊な車両の配備が要求されます。確固たる収益の柱があれば、シナリオの制限時間と戦いながら、一時的な運用赤字をカバーすることができます。

### キャンペーンミッション中、都市が貨物の受け入れを停止するのはなぜですか？
都市は、商業地区や工業地区の発展段階に応じて、現在需要のある貨物タイプしか受け入れません。加工食品しか求めていない都市に建材を大量に送り込んでも、配達は停滞し、荷積み場はパンクして評価が急落します。線路を敷設する前に、必ず都市の情報ウィンドウを開いて現在の需要を確認してください。

### 昼夜サイクルはTransport Fever 3のキャンペーン進行にどのように影響しますか？
昼夜サイクルは旅客の移動量と道路交通のパターンに影響を与えます。夜間は旅客の鉄道需要が低下するため、貨物輸送に活用できる空きダイヤが生まれます。日中のターミナル混雑を引き起こさずに旅客列車と貨物列車がスムーズに共存できるように運行計画を立てることが、ゲーム後半のキャンペーン実績を解除する鍵となります。

### 獲得し損ねたメダルを取るために、Transport Fever 3のキャンペーンシナリオを再プレイすることはできますか？
はい。ロック解除されたミッションは、メインシナリオメニューからいつでも個別に再プレイできます。後半のミッションで培った高度なルート計画の知識や信号制御の戦術を駆使して初期のチャプターをやり直せば、取り逃したサブメダルの回収や5つ星評価の獲得が格段に容易になります。
