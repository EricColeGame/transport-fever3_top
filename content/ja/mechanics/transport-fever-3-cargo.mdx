**Transport Fever 3の貨物**（cargo）ネットワークを極めるには、産業の生産チェーンと拡大する都市の急速な消費スピードとのバランスを取る必要があります。気軽なタイクーンビルダーであれ、リアルな運行を目指す鉄道ファンであれ、**Transport Fever 3の貨物**ロジスティクスを最適化できるかどうかが都市の成長と停滞を分けます。貨物輸送はプレイヤーの交通帝国の財政基盤であると同時に、ゲーム内で最も難易度の高い物流の壁でもあります。

産業ロジスティクスの管理は、単に鉄鉱石鉱山と製鉄所を線路で結ぶだけでは終わりません。成長を続ける大都市で100%の安定した供給率を維持するには、路線の運行頻度、ターミナルの処理能力、車両の積載容量、都市の保管タイマーを緻密に調整する必要があります。

## Transport Fever 3の貨物メカニクスと都市需要の仕組み

**Transport Fever 3の貨物**メカニクスが内部でどのように機能しているかを理解することは、収益性の高い貨物ネットワークを維持するうえで不可欠です。本作の都市は、その規模を拡大するために特定の商業・工業用完成品（工具、食糧、燃料、機械、建築資材、消費財など）を要求します。これらの物資を配送すると、都市は納入を記録して充足率を計算し、それが人口増加に直接影響を与えます。

しかし、都市は物資を無期限に保管してくれるわけではありません。納入された貨物は、内部の消費減衰タイマーに基づいて消費されていきます。もし列車やトラックが極端に長編成で稀にしか到着しない場合、局所的な供給率は一時的に100%まで跳ね上がった後、次の便が来る前にゼロ近くまで急落してしまいます。高い満足度を維持するには、散発的な巨大輸送よりも、途切れのない連続的な配送ストリームを維持することが求められます。

| 都市ランク | 目安人口 | 要求される貨物種別数 | 目標配送間隔 | 推奨メイン輸送車両 |
| :--- | :--- | :--- | :--- | :--- |
| **小規模な町** | 100 – 400 | 1 – 2 種類 | 90–120秒ごと | 中型配送トラック |
| **成長中の都市** | 500 – 1,200 | 2 – 3 種類 | 60–90秒ごと | 短編成の貨物列車 / 大型トラック |
| **地方拠点都市** | 1,300 – 2,000 | 3 – 4 種類 | 45–60秒ごと | 専用編成列車 ＆ 地域内配送網 |
| **大都市（メガロポリス）** | 2,000以上 | 要求される全品目 | 30–45秒ごと | 複線の貨物幹線 ＋ 複数トラック拠点 |

都市へ効率的に供給を行うため、生産施設は接続された目的地側の受け入れ能力に応じて動的に生産量を調整します。最終的な受け手側に有効な需要があり、かつ物流チェーン全体に十分な輸送容量が存在する場合にのみ、工場は貨物を出荷します。

## リアリズムのジレンマ：大量輸送のアーケード型 vs リアル志向の貨物運行

プレイヤー体験において大きな議論の的となっているのが、現代的な都市が要求する圧倒的な貨物量です。[Steam CommunityのTransport Fever 3ディスカッション](https://steamcommunity.com/app/3493540/discussions/0/591786249237420920/)に寄せられる継続的なコミュニティの報告によれば、ゲーム終盤の**Transport Fever 3の貨物**路線の管理は、常軌を逸した消費速度との果てしない追いかけっこになりがちです。

都市人口が2,500人に達すると、満足度を100%近くに維持するために、24時間体制で数十本もの大容量列車を運行する専用の複線鉄道コリドーが必要になるケースが多々あります。現実の鉄道運用を再現しようとして、製油所に1日数回だけ8両のタンク車を送り込むようなリアル志向のプレイヤーは、都市の満足度指標が一桁台に低迷するという現実に直面することがよくあります。

| シミュレーション要素 | 標準の「アーケード的」デフォルト挙動 | コミュニティ推奨の「リアル志向」設定 |
| :--- | :--- | :--- |
| **大都市の需要量** | 1サイクルあたり品目ごとに600–1,200個以上 | 1サイクルあたり品目ごとに50–100個 |
| **必要な配送頻度** | 減衰を防ぐため20–40秒ごと | ゲーム内時間で15–30分ごと |
| **列車の編成** | 20–30両の専行列車が絶え間なく到着 | 6–10両の混載貨物列車が定期的に到着 |
| **インフラへの負荷** | マップ上が並行線路で埋め尽くされる | 混合交通やヤード入換のスペースを確保可能 |
| **地域入換作業の実現性** | 実現困難（遅延が供給崩壊を招く） | リアルな操車場オペレーションが可能 |

開発元がきめ細かな難易度設定を導入するか、モッダーがグローバルなバランス調整MODを公開するまでは、仮想の指令員たるプレイヤーは自身の運行思想を選択しなければなりません。完璧な100%の数値を追い求めて超高頻度・大容量の自動コンベア路線を築くか、あるいは都市の成長率低下を受け入れて、見た目にも美しいリアルな地域混載列車を走らせるかのどちらかです。

## 拡張性の高い貨物コリドーと配送ハブの設計

大容量の**Transport Fever 3の貨物**ハブを設計する際、長距離貨物列車と都市中心部の配送車両を明確に分離することが鉄則です。大型の貨物列車をダウンタウンの商業中心地に直接乗り入れさせようとすると、壊滅的な道路渋滞が発生し、貴重な商業地を破壊し、騒音公害を急上昇させてしまいます。

ハブ・アンド・スポークモデルを採用すれば、これらの問題はすっきりと解決します。大量輸送列車が遠くの製造コンプレックスから都市郊外の複合貨物ターミナルへと完成品をピストン輸送します。そこから、より小型でクリーンな配送トラックが、指定された工業・商業の荷下ろしゾーンへと貨物を分散させていきます。

```
[原材料の採掘/採取] ---> [加工プラント] ---> [製造工場]
                                                |
                                      (幹線鉄道コリドー)
                                                v
[都市中心部の店舗] <--- (クリーンな電気トラック) <--- [都市郊外の貨物ハブ]
```

ロジスティクス網の各セクションに適した輸送モードを選択することで、交通渋滞を防ぎ、会社の収益を最大化できます。

| 輸送モード | 最適な距離 | 主な用途 | 最大の利点 | 主な制限事項 |
| :--- | :--- | :--- | :--- | :--- |
| **貨物鉄道** | 中距離〜長距離 | 大量資源、完成品 | 1路線あたりの圧倒的な輸送力 | 初期インフラ投資額が非常に高い |
| **トラック輸送** | 短距離〜中距離 | 都市への最終配送、序盤の輸送 | ルート設定の柔軟性が極めて高い | 輸送量が増えると都市部の渋滞を引き起こす |
| **内陸水運** | 長距離（平坦地形） | 鉱物資源、原油、大量の鋼鉄 | 1トンあたりの運行コストが最も低い | 航行可能な河川にルートが限定される |
| **航空貨物** | 超長距離 / 離島 | 高付加価値・軽量の完成品 | 地点間の迅速な輸送 | 積載容量が極めて小さく運行コストが非常に高い |

複数プラットフォームを持つ鉄道ハブでは、プラットフォームの割り当てを手動で設定してください。特定の路線に専用プラットフォームを割り当てておくことで、停車中の列車が塞いでいる番線を待つ間に、2本の列車がターミナルの分岐部全体を塞いでしまう信号トラブル（デッドロック）を回避できます。

## 配送タイマーの最適化とサプライチェーンの供給不足防止

**Transport Fever 3の貨物**の流れにおいて、一貫した配送間隔を保つことは生死を分けます。本作の経済シミュレーションは、年間の総輸送量ではなく「直近の納入履歴」に基づいて充足率を算出しています。仮に工場が年間1,200個の食糧を生産していても、4か月に1度しか訪れない超巨大列車1編成で運んでしまうと、都市は「過剰供給」と「完全な欠品」を交互に繰り返すことになります。

評価を安定させるには、工場の生産ペースに合わせて路線容量を調整し、運行間隔（ヘッドウェイ）を極力短くしてください。18両編成の巨大列車を1本走らせるよりも、6両編成の列車を等間隔で3本走らせた方が物資が安定して届き、都市の満足度をはるかに高く維持できます。

| 診断された問題 | ゲーム内での視覚的症状 | 根本的な原因 | 改善策 |
| :--- | :--- | :--- | :--- |
| **貨物の減衰（消費切れ）** | 配送と配送の合間に都市需要が0%まで落ちる | 列車の到着間隔（ヘッドウェイ）が長すぎる | 巨大編成をやめ、小型編成の高頻度運行に切り替える |
| **駅の過密（キャパオーバー）** | 警告アイコンとともにホームから貨物が消滅する | 駅の保管許容量を超過している | プラットフォームを延伸するか、貨物保管倉庫を追加する |
| **工場の生産停止** | 一次産業の生産が突然ストップする | 下流の受け入れターミナルで滞留が発生している | 輸送経路のボトルネックを解消するか、中間備蓄を増設する |
| **トラックの渋滞** | 最終マイルの配送トラックが都市の渋滞に巻き込まれる | 配送ルートが混雑した通勤路と交差している | 貨物専用バイパスや環状道路を敷設する |

路線の統計ウィンドウは定期的に確認しましょう。特に**頻度（Frequency）**と**輸送力（Rate）**の指標には注意を払ってください。路線の輸送力は受け入れ先都市の消費速度をわずかに上回る程度に設定し、供給スコアを最も安定させるために運行頻度は90秒未満を保つのが理想的です。

## 線路の渋滞を防ぎつつゲーム終盤の大都市を管理する方法

ゲーム後半の大規模なセーブデータでは、**Transport Fever 3の貨物**需要が地域の鉄道網を簡単に麻痺させてしまうことがあります。3つか4つの主要都市が密集している地域で、すべての産業へ個別に貨物路線を乗り入れさせると、分岐点がパンクし、旅客特急ネットワークが完全に停止してしまいます。

ネットワーク全体の麻痺を防ぐには、主要な旅客ターミナルの周囲に立体交差による貨物専用バイパスを建設してください。高架橋（フライオーバー）や地下道（ダイブアンダー）を用いて平面交差を排除すれば、高速旅客特急が過密な貨物コリドーの通過を待つことなくスムーズに走り抜けられます。

| ネットワークのボトルネック | 貨物フローへの影響 | 土木工学的アプローチ |
| :--- | :--- | :--- |
| **平面交差の競合** | 列車が信号待ちし、納入が遅れる | 立体交差（左折・合流用の跨線橋やトンネル）を建設する |
| **ターミナル進入路の混雑** | ハブ外の幹線上で進入待ち列車が渋滞する | 到着用の機回し線や複線のヤード進入路を増設する |
| **都市内配送の行き詰まり** | 路線バスの後ろに配送トラックが閉じ込められる | 一方通行の貨物専用レーンや地下荷下ろし場を設置する |
| **速度差による干渉** | 時速60マイルの貨物列車が時速125マイルの特急を遅延させる | 複々線化を実施（内側を特急専用、外側を貨物専用に分離） |
| **ターミナルホームの占有** | 貨物の積み込みが遅く、空の列車がホームを塞ぎ続ける | 積載設定を「満載まで待機」から「利用可能なら積載」に変更する |

貨物コリドーを地域の旅客交通から切り離すことで、大都市が何千個もの商業製品を要求するようになっても、交通帝国を定時運行、高収益、かつスムーズに保つことができます。

## よくある質問（FAQ）

### 工場が商品を生産しているのに、なぜ都市の貨物評価が下がるのですか？
本作における都市の満足度は、配送頻度と消費タイマーに直接連動しています。配送間隔が長すぎると、次の便が到着する前に都市が備蓄をすべて消費してしまい、満足度評価が急落します。これを解決するには、1本の大型列車ではなく、より小回りの利く編成を短い間隔で運行してください。

### プラットフォームから貨物が消えるのを防ぐにはどうすればよいですか？
貨物は、プラットフォームの物理的な保管上限を一定時間超え続けた場合に消失します。駅の過密を解消するには、貨物プラットフォームを延伸する、駅敷地内にモジュール式の貨物保管庫を設置する、または輸送力を増強して物資をより早く捌くようにしてください。

### Transport Fever 3で実用的な入換作業や操車場を作ることはできますか？
側線やウェイポイント（通過点）の指定を使って見た目上の操車場を構築することは可能ですが、バニラ（基本ゲーム）の自動配車システムは指定された路線上で貨物を自動配送します。複雑なヤード入換を行おうとすると大幅な遅延が生じ、シビアな配送タイマーに悪影響を与えるリスクがあります。ただし、専用の物流MODの導入や綿密なウェイポイント管理を行えば、リアルなヤード運行を楽しむことも可能です。

### キャンペーン序盤で最も収益性の高い貨物チェーンは何ですか？
穀物・家畜から「食糧」、あるいは原油から「燃料」といった、高需要でシンプルな2段階加工チェーンが序盤の事業として最も収益性が高くなります。これらは中間インフラの構築が最小限で済み、専用ながらも手頃な車両で運用できるため、より複雑な4段階加工（機械や工具など）のネットワークを構築するために必要な資金を素早く稼ぎ出すことができます。
